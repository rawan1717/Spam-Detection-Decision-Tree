# Spam Detection Using Decision Tree

## Overview
This project implements a spam detection model using a Decision Tree classifier. The notebook covers data preprocessing, model training, and performance evaluation.

## Features
- Data preprocessing
- Decision Tree classification
- Model evaluation using:
  - Accuracy
  - Precision
  - Recall
  - F1-score

## Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Files
- `Spam_Detection_DecisionTree.ipynb` – Complete implementation of the project.
